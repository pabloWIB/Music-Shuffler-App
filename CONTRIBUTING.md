# Contributing · Cómo colaborar

Thanks for wanting to help. Issues and pull requests are welcome in **English or Spanish**.
Gracias por querer ayudar: puedes escribir issues y pull requests en **español o inglés**.

## Run it locally · Correrlo en local

```bash
git clone https://github.com/pabloWIB/Music-Shuffler-App.git
cd Music-Shuffler-App
npm install
npm run dev
```

Node.js 20 or newer. The app opens at `http://localhost:3000`.

## Ground rules · Reglas del proyecto

1. **Nothing leaves the browser.** No backend, no database, no uploads, no account.
   *Nada sale del navegador: sin servidor, sin base de datos, sin cuentas.*
2. **The user is elderly and not technical.** Big buttons, large type, 7:1 contrast, plain Spanish.
   *La usuaria es mayor y no es técnica: botones grandes, letra grande, contraste 7:1.*
3. **Few dependencies.** Today there are three at runtime; add one only if it clearly pays for itself.
4. Run `npm run build` before opening a pull request.

## Where to start · Por dónde empezar

Look for issues labelled [`good first issue`](https://github.com/pabloWIB/Music-Shuffler-App/labels/good%20first%20issue)
or [`help wanted`](https://github.com/pabloWIB/Music-Shuffler-App/labels/help%20wanted). If you have a new idea,
open an issue first so we can agree on it before you write code.
